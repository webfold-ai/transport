# Security policy

Report vulnerabilities privately through GitHub's "Report a vulnerability" (Security tab of this
repository). Do not open a public issue for a suspected vulnerability. Include the module, version
or commit, and a reproduction. Expect an acknowledgement within a few working days.

This crate parses untrusted network input (wire frames, DNS, signed dial keys, gossip, ACME) and
handles key material; findings there are in scope.
